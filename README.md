# Sistema Integral de Gestión de Restaurante (SIGR)

## Descripción

Este repositorio corresponde a una práctica académica de Gestión del Software, enfocada en la documentación y el control de versiones de la línea base de un Sistema Integral de Gestión de Restaurante (SIGR).

El sistema propuesto busca facilitar la administración de las actividades de un restaurante mediante una aplicación web.

## Módulos propuestos

- Autenticación y gestión de usuarios.
- Administración del menú digital.
- Registro y seguimiento de pedidos.
- Gestión de reservas.
- Cierre de caja y reportes de ventas.

## Objetivo de la línea base

Establecer una versión de referencia de la documentación del proyecto, identificando sus componentes, criterios de validación y mecanismos de control de cambios.

## Herramientas utilizadas

- Git: control de versiones.
- GitHub: alojamiento del repositorio.
- GitHub Issues: seguimiento de cambios y tareas.
- Jenkins: herramienta propuesta para integración continua.
